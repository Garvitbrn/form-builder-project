# form-builder-project
Dynamic Form Builder – Full Stack Web Application:
  A full stack web application for creating, customizing, and managing dynamic no-code forms.
  This project allows admins to build forms visually without writing code and enables users to submit responses easily.
  Built as a full stack development project using modern web technologies.

Features:
  User Authentication (Login/Register),
  Dynamic Form Builder,
  Multiple Field Types,
  Form Management System,
  Public Form Access,
  Response Collection & Storage,
  Responsive UI Design,
  Secure REST APIs.

Supported Field Types:
  Text Input,
  Textarea,
  Dropdown,
  Checkbox,
  Radio Button,
  Email Field,
  Number Field.

Tech Stack:
  Frontend:
    HTML5,
    CSS3,
    JavaScript,
    React.js,
    Tailwind CSS.
  Backend:
    Node.js,
    Express.js.
  Database:
    MongoDB.
  Authentication:
    JWT,
    bcryptjs.

Features Included:
